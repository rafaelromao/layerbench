LayerBench simulates how text is typed on a ZMK keymap—including layers, combos, macros and other
supported key behaviors—and measures the resulting physical key presses against keyboard-layout
rules. Import a keymap, edit layouts, compare two side by side, and inspect or build rule sets. Choose
from bundled corpora or bring your own text to measure the languages a layout is designed for.

LayerBench is an analyzer, not a firmware builder or a complete ZMK runtime: unsupported behaviors
are not simulated, and its measurements do not replace trying a layout on the keyboard.

Start in the [app](https://layerbench.github.io/), read the [landing page](https://rafaelromao.github.io/layerbench/)
for an overview, or go straight to the [guide](https://layerbench.github.io/guide) for how-tos.
