# A user's documents are custom, and links name them `custom:`

The layouts, rule sets and texts a user keeps are all one thing, a custom document, as opposed to
the ones that come with the app, and the code, the words on the page and the links all say so. A
link names one as `custom:<id>`. "Saved" would read as a verb in some places and as a kind of
document in others, so it stays a verb: **Save**, and the "Saved {name}" message. The storage
format, the gist names and the paths on the `layerbench-data` branch say nothing of either word. A
link with `saved:` in it does not open, and nothing converts it: the cost is a link in that
spelling, and the gain is that nothing in the code has to know a second spelling.
