# Sources of the code and Markdown corpora

Generated by `pnpm corpora:extract` from `code-sources.json`: do not edit it by hand.

Each repository is read at the commit named here, and only for the files under the licence in
its row, which its licence file in that commit says (the build stops if it does not). What is
taken from a file is its lines with the comments, and the docstrings of the indentation
languages, removed; a line holding an address, a phone number, a key, a hash, a long word,
text that is not ASCII, or the words copyright, author or licence is left out whole, and so is
a code line with a capitalised pair of words in quotes, the shape of a name. Nothing is changed
in a line that stays. Each repository gives its share of its language, in an order fixed by a
hash, so the same sources always make the same text. The licence of each file stays that of its
repository; its notice is at the link in the Licence column. The projects of
`docs/research/code-corpora.md` are under `research` in `code-sources.json`; nothing of them is kept.

Regenerate, from a checkout of this repository:

```bash
pnpm corpora:fetch     # downloads the archives into packages/corpora/.cache (network)
pnpm corpora:extract   # writes raw/code-*.txt, raw/en-markdown-agents.txt and this file
pnpm corpora           # builds what the app serves from them
```
